# ♻️ Guia de Sustentabilidade

Este é um projeto de extensão universitária desenvolvido para facilitar o acesso da comunidade a informações essenciais sobre práticas sustentáveis. A aplicação funciona como um guia prático e objetivo, focado em educar sobre o descarte correto de resíduos e os objetivos sociais da preservação ambiental.

### 📌 Sobre o projeto
O app foi construído utilizando Angular e Ionic, garantindo uma interface moderna, responsiva e de fácil navegação. Conforme demonstrado na interface principal, o conteúdo é organizado em quatro pilares fundamentais:
- **Apresentação do Projeto:** Visão geral da iniciativa e seu público-alvo.
- **Objetivo Social:** Conscientização sobre a importância da separação de resíduos.
- **Coleta Seletiva:** Um guia rápido para implementação da coleta em residências.
- **Descarte Consciente:** Dicas práticas para o descarte responsável no cotidiano.

### 🎯 Objetivo do projeto
O objetivo deste projeto é oferecer uma interface minimalista e de rápida navegação para educar a comunidade sobre práticas sustentáveis. 

### 🛠️ Tecnologias Utilizadas

- **Frameworks:** Angular e Ionic.

- **Linguagem:** TypeScript.

- **Estilização:**  SCSS/CSS (localizado na pasta theme/variables.scss).

- **Gerenciador de Pacotes:** npm.

- **Versionamento:** Git e GitHub.

### 📂 Estrutura do Ambiente de Desenvolvimento
O projeto segue a estrutura padrão do ecossistema Ionic/Angular, com foco nos seguintes diretórios:

`src/app/`: Contém a lógica e os componentes das páginas (como coleta-seletiva, descarte, etc.).

`src/theme/`: Onde estão as variáveis globais de estilo e cores.

`angular.json:` Configurações globais do framework Angular.

## 🚀 Como executar o projeto
Para rodar este mini app localmente, siga os passos abaixo:
1. Clone o repositório:
```bash
git clone https://github.com/gabriellicabral/guiadesustentabilidade.git
```

2. Instale as dependências:
```bash
npm install
```

3. Execute o servidor de desenvolvimento:
```bash
ionic serve
```

### 📈 Fluxo de Trabalho (Git)
O desenvolvimento deste projeto foi acompanhado através do Git para garantir o versionamento e a organização do código:

`git init`: Inicialização do repositório local.

`git add .`: Adição dos arquivos para versionamento.

`git commit`: "Mensagem objetiva"`: Registro das alterações realizadas.

`git push`: Envio das atualizações para o repositório remoto no GitHub.
